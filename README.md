## Struktura

- `docs/01-introduction/` — Linux, kernel, dystrybucje, instalacja, filesystem, użytkownicy i CLI.
- `docs/02-cli/` — powłoki, komendy, pliki, strumienie, grep/find/history.
- `docs/03-users-permissions/` — piping, awk, user/group management, permissions, SUID/SGID/PATH.
- `docs/04-network-system/` — ping/traceroute, konfiguracja sieci, APT, Apache i diagnostyka usług.
- `docs/05-services-hardening/` — SSH/SCP, FTP, Samba, usługi i hardening.
- `docs/06-bash/` — Bash, I/O, warunki, operatory, backupy, integrity monitoring i cron.
- `docs/07-host-security/` — mounting, GRUB/LUKS, PAM, SELinux/AppArmor, privilege escalation i cron security.
- `docs/08-network-security/` — iptables, firewalld, Fail2Ban, monitoring logów, Apache, ModSecurity, TLS i SFTP.
- `docs/labs/` — 30 laboratoriów.
- `docs/projects/` — final project.
- `docs/reference/` — komendy, ścieżki, protokoły, narzędzia, hardening, glossary, linki i source map.

# Glossary

[← Indeks wiki](../index.md)

- **CLI** — command-line interface.
- **Shell** — interpreter poleceń, np. Bash, sh, Zsh.
- **Kernel** — rdzeń systemu zarządzający sprzętem, pamięcią, procesami i system calls.
- **Distribution** — system oparty o kernel Linux + zestaw narzędzi, pakietów i polityk.
- **Root** — konto superusera.
- **Sudoer** — użytkownik uprawniony do wykonywania wybranych poleceń z podwyższonymi uprawnieniami.
- **SUID / SGID** — specjalne bity uprawnień zmieniające effective user/group lub zachowanie grupy katalogu.
- **PATH** — lista katalogów przeszukiwanych przy wywoływaniu programów.
- **stdin/stdout/stderr** — standardowe strumienie wejścia, wyjścia i błędów.
- **Pipe** — `|`, przekazuje output jednego programu do inputu kolejnego.
- **Daemon** — proces/usługa działająca w tle, np. `sshd`.
- **Hardening** — ograniczanie powierzchni ataku i wzmacnianie konfiguracji.
- **PAM** — Pluggable Authentication Modules, mechanizm wspólnych polityk uwierzytelniania.
- **LUKS** — standard szyfrowania dysków Linux.
- **GRUB** — boot loader.
- **Cron / crontab** — mechanizm harmonogramowania cyklicznych zadań.
- **File integrity monitoring** — wykrywanie zmian na podstawie znanej wartości/hasha.
- **iptables / firewalld** — mechanizmy zarządzania zaporą sieciową w Linux.
- **Fail2Ban** — narzędzie reagujące na wzorce nadużyć w logach przez czasowe blokowanie źródeł.
- **ModSecurity** — moduł/WAF używany do filtrowania żądań HTTP; w kursie łączony z OWASP CRS.

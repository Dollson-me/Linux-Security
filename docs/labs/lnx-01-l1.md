distribution, and discover their differences.

Your research should focus on the following distributions:

- Ubuntu

- RHEL (Red Hat Enterprise Linux)

- CentOS

- OpenSUSE

Extra:

- Are there any other Linux distributions worth mentioning?

- Does any manufacturer ship computers with Linux from the factory?

This is good practice for Google searching. Let students read about the OS, but make

sure they do not concentrate on irrelevant details, such as the year of creation.

Ubuntu

1. Yes, Ubuntu is based on Debian.

2. The Ubuntu distribution is maintained by Canonical.

3. Although Ubuntu supports servers, it is mainly intended for home users.

4. Ubuntu is primarily meant for personal use.

RHEL

1. Yes, the base code of RHEL was used to create CentOS.

2. RHEL is maintained by Red Hat.

3. RHEL is the only distribution in the list that offers subscriptions for pay.

4. RHEL is intended for enterprise and commercial use.

**PDF s. 10:** CentOS

1. Yes, CentOS was based on the code of RHEL.

2. CentOS is community-supported and maintained indirectly by RedHat.

3. CentOS is an exact copy of RHEL, only without pay subscriptions.

4. CentOS is intended for enterprise and commercial use.

Debian

1. Yes, Debian was used as the base for Ubuntu.

2. Debian is community-supported and maintained by the Debian Project.

3. Debian is one of the oldest Linux distributions, and many others are based on it.

4. Debian is intended mainly for servers but can easily be customized for personal use.

OpenSUSE

1. No, it is based on SUSE Linux Professional.

2. OpenSUSE is developed and maintained by SUSE Linux GmbH.

3. OpenSUSE has a special tool called YaST which was especially developed for

OpenSUSE.

4. OpenSUSE was designed especially for developers and system administrators. It

provides a desktop environment with server-related tools.

Other important distributions:

- Arch Linux

- Fedora

- Linux Mint

- Slackware

- Kali

- Pop_!

- Raspberian

Do any manufacturers ship with Linux?

Large-scale manufacturers today who ship machines with Linux include Dell, HP,

IBM/Lenovo, System76, and others.
